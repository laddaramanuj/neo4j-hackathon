BAgent runtime — LangChain 1.4

  • create_agent(model, tools, system_prompt) on the LangGraph runtime; tool-calling loop, recursion_limit=14
  • Model: ChatOpenAI → OpenRouter (openai/gpt-4.1-mini, temperature 0.2)
  • Memory-first: the customer's memory is read from Neo4j and injected into the system prompt every turn
  • Policy: new report → payments + clues + graph search + advisories + open case; follow-up → answer from memory without re-asking
  • Tools are closures bound to the customer id on the server; the LLM never chooses whose data it reads
  • Language: preference detection → Preference node → replies in Hindi / Marathi / English
  • Fallback: deterministic pipeline with the same tools if the agent errors

GGuardrails

  • The LLM never writes Cypher: every write is a fixed, parameterised query in one transaction
  • Retrieval is scoped to nodes connected to this customer's case (not global similarity)
  • Replies use only retrieved facts; other customers' names are never revealed
  • Never asks for OTP, PIN, card number or password; advises 1930 / cybercrime.gov.in
  • Secrets only in .env / Streamlit Secrets, git-ignored; all data synthetic, phones in the invalid +91 5XXXX range
